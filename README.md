# طريقة تشغيل المشروع

## 1. تحميل المشروع

قم بتحميل المشروع ثم افتحه باستخدام **Visual Studio Code** أو محرر الأكواد الذي تفضله.

## 2. تثبيت المشروع

افتح **Terminal** أو **Command Prompt** داخل مجلد المشروع، ثم نفّذ الأمر التالي:

```bash
pip install -e .
```

هذا الأمر يقوم بتثبيت المشروع في وضع **Editable**، بحيث يمكنك تعديل الكود مباشرة أثناء تطوير المشروع دون الحاجة إلى إعادة تثبيته بعد كل تعديل.

## 3. تشغيل الأداة

من نفس مجلد المشروع، استخدم الأمر:

```bash
ftool
```

ثم أضف الأمر والخيارات التي تريد تنفيذها.

### مثال: حذف ملف

لحذف ملف باسم `f.txt`:

```bash
ftool del f.txt
```

بشكل افتراضي، يقوم الأمر `del` بنقل الملف إلى **سلة المحذوفات الخاصة بالأداة** بدلًا من حذفه نهائيًا.

### مثال آخر

لحذف مجلد بشكل recursive:

```bash
ftool del -r my_folder
```

> **ملاحظة:** يجب تنفيذ أوامر `ftool` من Terminal بعد تثبيت المشروع باستخدام `pip install -e .`.
